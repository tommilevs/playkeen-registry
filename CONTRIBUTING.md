# Playkeen contributions

Application repositories should use the `keenplay-<app-id>` naming convention, include a `playkeen.yaml` manifest, and publish installable assets through GitHub Releases. Translation contributions update `locales/<code>.json`; English is the canonical key set. Registry entries are reviewed by automation before merging.

## Русский

Репозитории приложений должны использовать соглашение `keenplay-<app-id>`, содержать manifest `playkeen.yaml` и публиковать устанавливаемые файлы через GitHub Releases. Переводы добавляются в `locales/<code>.json`; английский является каноническим набором ключей. Записи каталога проверяются автоматикой.
